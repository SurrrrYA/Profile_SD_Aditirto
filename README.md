# Website MI Aditirto

Website profil dan informasi MI Aditirto yang digunakan untuk menampilkan informasi sekolah kepada masyarakat serta memudahkan administrator dalam mengelola konten website.

## Deskripsi

Website MI Aditirto merupakan sistem informasi berbasis web yang menyediakan berbagai informasi mengenai madrasah, seperti profil sekolah, berita, prestasi, agenda kegiatan, galeri, serta informasi kontak.

Website juga dilengkapi dengan halaman administrator yang digunakan untuk mengelola konten dan informasi yang ditampilkan pada website.

## Fitur

### Halaman Pengunjung

- Halaman Home
- Profil Sekolah
- Berita dan detail berita
- Galeri
- Prestasi
- Agenda kegiatan
- Informasi kontak
- Form pesan kontak
- Informasi lokasi sekolah

### Halaman Administrator

- Login administrator
- Dashboard admin
- Kelola konten Home
- Kelola Profil Sekolah
- Kelola Berita
- Kelola Prestasi
- Kelola Struktur Guru
- Kelola Pesan Kontak
- Upload gambar dan media
- Edit dan hapus data
